# 📦 Next.js Font Optimization - সম্পূর্ণ নির্দেশিকা

এই প্রজেক্টে Next.js ফন্ট অপ্টিমাইজেশনের সব ধরনের নিয়ম ও বেস্ট প্র্যাকটিস অন্তর্ভুক্ত রয়েছে।

## 🚀 Font Optimization পদ্ধতিসমূহ

### 1. **Next.js Built-in `next/font`**
```javascript
// app/layout.js বা pages/_app.js
import { Inter, Roboto_Mono } from 'next/font/google'

const inter = Inter({
  subsets: ['latin', 'bengali'],
  display: 'swap',
})

const robotoMono = Roboto_Mono({
  subsets: ['latin'],
  display: 'swap',
})

export default function RootLayout({ children }) {
  return (
    <html lang="en" className={inter.className}>
      <body>
        <div className={robotoMono.className}>{children}</div>
      </body>
    </html>
  )
}
```

### 2. **কাস্টম ফন্ট (Local Fonts)**
```javascript
import localFont from "next/font/local";
import "./globals.css";

// একক ফন্ট ফাইলের জন্য
const myFont = localFont({
  src: '../../public/local fonts/Nikosh/Nikosh.ttf'
})

// একাধিক ফন্ট ফাইল (Multiple weights/styles)
const myFontFamily = localFont({
  src: [
    {
      path: '../../public/local fonts/SolaimanLipi/SolaimanLipi-Thin.ttf',
      weight: '100',
      style: 'thin',
    },
    {
      path: '../../public/local fonts/SolaimanLipi/SolaimanLipi-Normal.ttf',
      weight: '400',
      style: 'normal',
    },
    {
      path: '../../public/local fonts/SolaimanLipi/SolaimanLipi-Bold.ttf',
      weight: '700',
      style: 'bold',
    },
    {
      path: '../../public/local fonts/SolaimanLipi/SolaimanLipi-Black.ttf',
      weight: '900',
      style: 'black',
    }
  ],
  variable: '--font-solaimanlipi', // CSS variable হিসেবে ব্যবহারের জন্য
  display: 'swap',
})

export const metadata = {
  title: "Next.js Font Optimization",
  description: "Generated by create next app",
};

export default function RootLayout({ children }) {
  return (
    <html lang="en" className={myFontFamily.variable}>
      <body className={myFontFamily.className}>
        {children}
      </body>
    </html>
  );
}
```

### 3. **Google Fonts অপ্টিমাইজেশন**

import { GoogleFont } from 'next/font/google'

// সাবসেট নির্ধারণ

## ⚡ অপ্টিমাইজেশন টিপস

### **Performance Best Practices:**
1. **Preload কোর ফন্টস:** শুধুমাত্র প্রয়োজনীয় ওজন প্রিলোড করুন
2. **সাবসেট ব্যবহার:** শুধুমাত্র প্রয়োজনীয় ভাষা সাবসেট যোগ করুন
3. **`display: 'swap'`:** FOIT/FOUT সমস্যা সমাধান
4. **Variable Fonts:** একাধিক ওজন ম্যানেজ করা সহজ
5. **Font Loading Strategy:** কৌশলগতভাবে লোডিং ম্যানেজ করুন

### **ফাইল ফরম্যাট প্রায়োরিটি:**
1. `.woff2` (সর্বোত্তম কম্প্রেশন)
2. `.woff`
3. `.ttf`
4. `.otf`

### **একাধিক ফন্ট ফাইল ব্যবস্থাপনা:**
```javascript
// বিভিন্ন weight এবং style একসাথে ব্যবহার
const customFont = localFont({
  src: [
    // Regular variants
    {
      path: './fonts/MyFont-Regular.woff2',
      weight: '400',
      style: 'normal',
    },
    {
      path: './fonts/MyFont-Italic.woff2',
      weight: '400',
      style: 'italic',
    },
    
    // Bold variants
    {
      path: './fonts/MyFont-Bold.woff2',
      weight: '700',
      style: 'normal',
    },
    {
      path: './fonts/MyFont-BoldItalic.woff2',
      weight: '700',
      style: 'italic',
    },
    
    // Light variants
    {
      path: './fonts/MyFont-Light.woff2',
      weight: '300',
      style: 'normal',
    },
  ],
  
  // CSS variable হিসেবে ব্যবহার
  variable: '--font-custom',
  
  // Performance optimization
  display: 'swap',
  preload: true,
  
  // Fallback fonts
  fallback: ['system-ui', 'arial'],
  
  // Adjust font metrics
  adjustFontFallback: true,
})

// ব্যবহার করার সময়
export default function Layout({ children }) {
  return (
    <html lang="en" className={customFont.variable}>
      <body className={customFont.className}>
        {/* বিভিন্ন weight ব্যবহার */}
        <h1 className="font-bold">Bold Text</h1>
        <p className="font-normal">Regular Text</p>
        <p className="font-light italic">Light Italic Text</p>
      </body>
    </html>
  )
}
```

### **CSS Variables মাধ্যমে Weight কন্ট্রোল:**
```css
/* globals.css */
:root {
  --font-weight-thin: 100;
  --font-weight-light: 300;
  --font-weight-regular: 400;
  --font-weight-medium: 500;
  --font-weight-bold: 700;
  --font-weight-black: 900;
}

/* ব্যবহার */
.thin-text {
  font-weight: var(--font-weight-thin);
}

.bold-text {
  font-weight: var(--font-weight-bold);
}
```

## 🛠️ ট্রাবলশুটিং

### সাধারণ সমস্যা ও সমাধান:
1. **ফন্ট ফ্লিকারিং:** `display: 'swap'` ব্যবহার করুন
2. **লেআউট শিফট:** `font-size-adjust` প্রোপার্টি ব্যবহার করুন
3. **ধীর লোডিং:** CDN ব্যবহার করুন এবং ফন্ট সাবসেটিং করুন
4. **একাধিক ফন্ট ফাইল লোড:** শুধুমাত্র প্রয়োজনীয় weights প্রিলোড করুন

### **একাধিক ফন্ট ফাইল ব্যবস্থাপনা টিপস:**
```javascript
const optimizedFont = localFont({
  src: [
    // শুধুমাত্র প্রয়োজনীয় weights লোড করুন
    {
      path: './fonts/Primary-Regular.woff2',
      weight: '400', // শুধুমাত্র regular weight
    },
    {
      path: './fonts/Primary-Bold.woff2',
      weight: '700', // শুধুমাত্র bold weight
    },
  ],
  // বাকি weights-এর জন্য fallback ব্যবহার করুন
  fallback: ['system-ui', 'Segoe UI', 'Roboto', 'Arial'],
  
  // Performance optimization
  preload: true, // শুধুমাত্র preload critical fonts
  display: 'optional', // optional swap for better performance
})
```

## 📈 Best Practices Summary

1. **Preload Critical Fonts Only:** শুধুমাত্র প্রথম পেজের জন্য প্রয়োজনীয় ফন্ট প্রিলোড করুন
2. **Use WOFF2 Format:** সর্বোত্তম কম্প্রেশন এবং পারফরম্যান্স
3. **Limit Font Weights:** সাধারণত 2-3টি weight (regular, bold) যথেষ্ট
4. **Implement Font Display Swap:** FOIT/FOUT সমস্যা সমাধান
5. **Use CSS Font Display API:** বেটার কন্ট্রোলের জন্য
6. **Monitor Performance:** Web Vitals ব্যবহার করে মনিটর করুন
7. **Implement Fallback Fonts:** ফন্ট লোড না হলে alternative
